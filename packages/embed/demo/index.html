Enquiry widget preview

This page loads deliberately hostile styles: every form control on it is set to a dashed magenta border at 22px. The widget is unaffected because it renders inside a shadow root. That isolation is the whole reason it can be dropped into an unknown theme without a rehearsal.

Putting it on the site

<div id="ukn-enquiry"></div>
<script src="https://crm.uknitrates.com/ukn-enquiry.js"
        data-endpoint="https://crm.uknitrates.com"
        data-mount="#ukn-enquiry"
        data-phone="01553 817744"
        data-surface="dark"></script>

Add the site's origin to UKN_PUBLIC_ORIGINS on the server, or the browser will refuse the cross-origin post.
