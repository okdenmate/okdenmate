# What is still unknown

Half the figures this system shows carry an Assumed tag. These are the reasons.
The register is live inside the application at `#questions`, where each question
can be marked as being chased and its answer recorded; this file is the standing
summary.

The rule the whole system follows: **a number nobody has verified is never
presented as a fact.** Where a figure was needed to make a screen work it is
tagged, and where it was not available the screen says so.

---

## Tier one — the forecast does not work without these

### Q2 · What is the buy and sell price on specialty nitrates?

Every specialty figure rests on an assumed 20 to 30 per cent gross margin. If the
real number is 10 per cent, the growth case halves. If it is 40, the business has
been under-selling itself for a year.

**Blocks:** the mix-shift comparison, the pipeline forecast, every product margin
band, the commission projection.
**How to answer:** three to five recent specialty orders with price and cost
against them.

### Q11 · What is the current enquiry volume and conversion rate?

Both primary contact routes on the live site are broken, so there is no enquiry
history to plan against. This system provides the endpoint that was missing; the
answer arrives roughly a month after the site is repointed at it.

**Blocks:** funnel benchmarks, stage close-probabilities, the pipeline forecast.

### Q12 · Does the new-account commission rate apply to that account's later orders?

Not written down. If the 25 per cent rate is first-order only, every projection
halves. The engine takes the conservative reading by default, so nothing is
inflated by an entitlement that was never agreed.

**Blocks:** the commission engine, the earnings projection.
**How to answer:** put it in the compensation agreement, in writing.

### Q18 · Is analytics installed on either site?

Arrival and engagement events fire into nothing without it, so the top of the
funnel stays dark. Note that this system's own event endpoint works regardless,
so the answer changes what is measurable, not whether anything is.

## What each unknown does to the interface

| Unknown | What you see instead of a number |
|---|---|
| Specialty margin (Q2) | Mix-shift figures tagged **A**, with the caveat printed beneath them |
| Storage rate (Q3) | The month raised as **unresolved**, not as £0, and no commission accrued |
| Peak tonnage (Q13) | All three notification positions flagged, and storage marked not sellable |
| Pallet positions (Q15) | Capacity shown as **Not known**, tagged **U** |
| Enquiry history (Q11) | Stage probabilities labelled as assumed, and the forecast labelled a ranking device |
| Analytics (Q18) | The funnel diagnosis says the zeroes are zero for the wrong reason |

Answer a question in the application and the figures it blocks stop being
assumptions. That is the point of holding the register inside the system rather
than in a document.
